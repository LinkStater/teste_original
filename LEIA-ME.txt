RANFY — LOGIN, QR CODE E AVALIAÇÃO

Como testar:
1. Extraia a pasta do projeto.
2. Abra a pasta no VS Code e use Live Server ou publique no Netlify (HTTPS).
3. Ao abrir pela primeira vez, o site pede o nome e guarda no localStorage deste navegador.
4. Na página de QR Code, autorize a câmera. O QR Code deve conter diretamente PROJETO_001, PROJETO_002, PROJETO_003 ou uma URL com ?projeto=CODIGO.
5. Para testar, cadastre/edite códigos em js/projects.js. QR codes não cadastrados serão recusados.
6. Ao enviar as notas obrigatórias, abre concluida.html; o botão retorna à página inicial.

IMPORTANTE SOBRE O BANCO DE DADOS:
Neste pacote, js/projects.js é um catálogo local de demonstração e as avaliações são salvas no localStorage do navegador. Isso não é um banco de dados compartilhado: outros celulares não verão automaticamente esses dados. Para produção/evento real, conecte a um backend (por exemplo, Supabase/Firebase ou uma API) e valide os códigos no servidor.

A câmera requer HTTPS (Netlify, GitHub Pages etc.) ou localhost, permissão do navegador e internet para carregar html5-qrcode e Pixelify Sans.
